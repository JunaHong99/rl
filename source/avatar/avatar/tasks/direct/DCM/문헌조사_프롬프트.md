# 문헌 조사 프롬프트 — 리더-팔로워 닫힌사슬 양팔 운반 포지셔닝 (2026-07-27)

## 조사 목적
우리 연구 = **GNN(kinematic graph) 기반 리더-팔로워 닫힌사슬 양팔 협동 운반 + 파지/base/로봇 형태 일반화(zero-shot)**.
핵심 질문: **기존 플래너/제어 기반 방법 대비 우리(학습+GNN 일반화)가 진짜 새롭고 우위가 있는가?**
→ "단순 운반은 IK/플래너로 충분한데 왜 RL/GNN?"에 답할 근거 확보.

---

## A. 직접 선행연구 (가장 중요 — 우리와 같은 문제 설정)

### A1. Hong2025이 인용한 Cui et al. (leader-follower chair transport)
```
검색어:
- "Cui leader-follower dual-arm chair transportation reinforcement learning"
- "leader-follower path planning dual manipulator closed chain damped least squares"
확인할 것:
- 플래너/제어 기반인가 RL인가? (Hong2025 [25]번 인용, follower=DLS)
- 파지/로봇 일반화를 다루나, 아니면 고정 셋업인가?
- 우리와 직접 비교 대상인가?
```

### A2. Hong2025 본체 재확인 (이미 읽음, 위치 재확인용)
```
- "A Novel Deep Reinforcement Learning path/force cooperative regulation dual-arm"
- 리더=RL 관절증분, 팔로워=IK, force agent. 고정 로봇. → 우리 차별 = GNN 일반화.
```

## B. 닫힌사슬 양팔 운반 — 플래너/제어 기반 (기존 성숙 분야)

### B1. 리더-팔로워(master-slave) + 제약 IK
```
검색어:
- "master-slave dual-arm closed kinematic chain manipulation control"
- "leader-follower bimanual object transport constrained inverse kinematics"
확인: 리더-팔로워 구조가 얼마나 표준적인가? 우리 제어 구조가 새로운가(아님으로 예상).
```

### B2. 협조 제어 + 내력(internal force) 분해
```
검색어:
- "dual-arm cooperative manipulation internal force control object impedance"
- "symmetric formulation bimanual manipulation external internal wrench"
확인: 내력 제어가 얼마나 표준인가 → 우리가 내력을 리워드로 학습하는 게 차별인지.
```

### B3. 닫힌사슬 제약 하 모션 플래닝 (RRT류)
```
검색어:
- "closed-chain constraint motion planning dual-arm RRT constraint manifold"
- "CBiRRT constrained bimanual manipulation planning"
확인: 플래너가 파지/경로를 얼마나 잘 푸는가 → "그냥 플래너 쓰지" 반론의 실체.
```

## C. 학습 기반 양팔 협동 조작 (우리 방법론 계열)

### C1. RL 양팔 협동 조작 (일반)
```
검색어:
- "reinforcement learning bimanual cooperative manipulation rigid object"
- "deep RL dual-arm coordinated transport closed chain"
확인: RL을 왜 썼나(플래너 대비 명시된 우위) → 우리 정당화 논거 수집.
```

### C2. GNN/graph 정책 + 조작 일반화 (우리 핵심)
```
검색어:
- "graph neural network policy manipulation morphology generalization"
- "GNN reinforcement learning multi-robot manipulation zero-shot transfer"
- (이미 아는 것: NerveNet, RoboBallet, One Policy to Control Them All, CASH)
확인: 닫힌사슬 협동 운반에 GNN 일반화를 적용한 선행이 있나?
      (RoboBallet=자유팔 다중 계획·닫힌사슬 아님. 우리 차별=닫힌사슬+든물체+GNN일반화.)
```

### C3. 파지/배치 일반화 (grasp pose, base spacing)
```
검색어:
- "grasp pose generalization dual-arm manipulation policy"
- "robot base placement generalization cooperative manipulation learning"
확인: 파지 pose·base 간격 일반화를 zero-shot으로 다룬 학습 연구 → 우리 1차목표 신규성.
```

## D. 결정적 질문 (조사로 답할 것)

1. **리더-팔로워 닫힌사슬 운반 자체**가 새로운가? → **아닐 것**(Cui et al. 등 선행). 우리 신규 = 그 위 **GNN 일반화.**
2. **파지+base 일반화**를 플래너가 이미 잘 하나? → 파라미터라 매번 재계산으로 가능할 것 → **우리 우위는 "재계산 없는 zero-shot"인데 그게 실용적 우위인지** 판단.
3. **기존 학습 연구가 명시한 "플래너 대비 우위"** 논거는? → 우리도 그걸 써야 함 (반응성/제약처리/일반화).
4. **닫힌사슬 + GNN + 형태일반화 조합**이 정말 빈자리인가? → 있으면 신규성 확보, 없으면 차별점 재정의.
