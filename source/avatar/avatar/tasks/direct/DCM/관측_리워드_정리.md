# DCM 학습 Observation / Reward 정리

> 현재 구성: **leader-follower + kinematic 그래프(KinMLP) + no_obstacles + no_gravity**, SAC + HER.
> 제어 5Hz(decimation 48, sim dt 1/240), **에피소드 30 step**(episode_length_s=6.0).

---

## 1. 태스크 구조 (leader-follower)

닫힌사슬 양팔이 rod를 함께 들고 목표 pose로 운반.
- **리더(arm1)**: 네트워크가 **7-DoF 관절 Δq** 출력(학습 대상).
- **팔로워(arm2)**: 리더 *명령* config의 FK로 rod pose 역산 → per-env grasp offset으로 팔로워 EE 목표 → **IK 추종**(feedforward, 12 iter warm-start). 학습 안 함.
- 두 팔 항상 일관 → 내력 낮음, 협응 학습 불필요(freeze 회피).

### Action
- **7-dim** = 리더 관절 Δq. squashed Gaussian: `action = action_scale · tanh(u)`, `action_scale = joint_dq_scale = 0.30` rad.
- 적용: `q1_des ← q1_des + 0.30 · action` (누적 setpoint), ImplicitActuator 포지션 모드(kp400/kd150/eff87)로 PhysX가 제어+용접제약 co-solve.

## 2. Observation (kinematic 그래프, KinMLP는 flatten)

**17 노드 그래프.** KinMLP는 `[전 노드 feature(170) + 전 엣지 feature(442) + global(11)] = 623` 을 flatten해 MLP 입력. (KinGNN은 같은 정보로 message passing.)

### 노드 (17개, 고정 인덱스)
| idx | 노드 | type |
|---|---|---|
| 0 | base_L (리더 base) | base |
| 1..7 | joint_L 1~7 (리더 관절) | joint ← **출력 head** (리더 Δq 7) |
| 8 | rod (object) | object |
| 9 | base_F (팔로워 base) | base |
| 10..16 | joint_F 1~7 (팔로워 관절) | joint (backbone 참여, 출력 X) |

### 노드 feature (10 = raw 7 + type one-hot 3)
- **base**: raw 0 (identity) — 위치정보는 엣지에.
- **joint**: 회전축(3, 부모frame 기준 상수=DH) + 관절값 sin/cos(2) + joint margin(min·max 2) = 7.
- **object(rod)**: raw 0 (identity) — goal오차는 global로 이동, rod 노드는 grasp 엣지의 공간 앵커.

### 엣지 feature (13 = type one-hot 4 + geom 9), 전부 양방향, receiver-frame 상대 pose = trans(3)+rot6d(6)
| type | 엣지 | 인코딩 |
|---|---|---|
| base→first | base ↔ joint1 | 마운트 |
| joint-chain | joint_i ↔ joint_{i+1} | DH 고정변환 = **링크길이** |
| **grasp** | joint7(EE) ↔ rod (양팔) | **파지 폭 + 각도** |
| **base-rel** | base_L ↔ base_F | **base 간격/자세** ← 베이스 랜덤화가 여기 반영 |

### Global feature (11)
`time(1) + f_int(1) + goal오차[리더 base frame: pos(3) + rot6d(6)] = 11`
- goal오차 = (goal_rod − rod) pose, **리더 base frame**(액션과 좌표계 정렬).
- rot6d = Zhou et al. 6D 회전 표현(특이점 없음).
- f_int = 양팔 grasp wrench 차이의 내력 크기(0.01 스케일).

> ★ 설계 요지: 노드=국소(부모기준 불변), 공간관계=엣지. base 간격·파지·링크길이가 전부 엣지라 **morphology(파지·베이스) 일반화**에 강함.

## 3. Reward

성공 판정 = **pos_err < 0.02m(20mm) AND rot_err < 0.1745rad(10°) 동시** (같은 step).

### 현재 구성에서 활성 항
| 항 | 값/식 | 비고 |
|---|---|---|
| **r_progress** (dense) | `10 · (prev_dist − cur_dist)` | `dist = pos_err + 0.1·rot_err` (Cartesian rod). lf_dense_w=10, lf_rot_weight=0.1 |
| **r_success** (sparse) | `+100` (에피소드 첫 동시도달 1회) | 도달 시 episode terminate |
| **r_time** | `−0.2 / step` | 게으름 방지 |
| **r_smooth** | `−0.01 · Σ(aₜ − aₜ₋₁)²` | 액션 급변(가속) 페널티 |

### 현재 OFF (0)인 항
- **r_internal** (내력): leader-follower에선 `_internal_w=0` → OFF. (joint_action 모드에서만 w_internal=0.002 활성.)
- **r_clearance / r_collision / r_filter** (장애물): `--no_obstacles`(n_obstacles=0)라 전부 0.
- **r_null** (nullspace): action 7-dim(≥8 아님)이라 0.
- **r_safety / r_joint_pbr**: 진단용, 0.

### 총합
`total = r_progress + r_success + r_time + r_smooth` (나머지 항 0).

---

## 4. HER (Hindsight Experience Replay)

- strategy `random_task`, k_future=1, her_progress_weight=100.
- **goal-무관 항**(`r_time + r_smooth + r_clearance + r_collision + r_null + r_filter`)은 relabel 시 그대로 보존.
- **goal-의존 항**(r_progress + r_success)은 virtual goal 기준 재계산(`recompute_reward`, Cartesian pos_err + 0.1·rot_err).
- 관측의 goal오차(global u)도 virtual goal로 교체(`replace_goal_in_kin_global`).
