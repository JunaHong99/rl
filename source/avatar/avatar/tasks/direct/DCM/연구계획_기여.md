# 연구 계획 / 기여 정리 (2026-07-27)

닫힌사슬 양팔 협동 운반 — 리더-팔로워 + kinematic-graph GNN + RL.
이 문서 = **무엇을 기여로 삼고, 왜 GNN/RL이 정당한가, 무엇을 실험으로 보일까**.

---

## 0. 현재까지 (검증됨)
- object-centric 파지 일반화 = 컨트롤러가 처리해 공짜(94%) → 네트워크가 기구학 안 배움 → morphology 토대 없음.
- **리더-팔로워**(리더 관절 Δq 학습 + 팔로워 IK) 전환. 고정 파지 운반 성공(MLP 85%).
- **kinematic 그래프**(17노드: base2+joint14+rod, 엣지4타입) + KinGNN → 고정 태스크 **GNN 93.7%>MLP 85%**(동시도달 기준 재평가 시 86.8%). 그래프가 이김.
- 파지 변이 학습 진행 중(grasp 엣지 = 파지 폭 d·각도 θ 인코딩).

---

## 1. ★ 문제의 본질 (2026-07-27 명확화)
학습 대상 = **"파지 pose가 이러할 때, 리더가 어느 경로로 가야 (a)팔로워 IK가 존재하고 (b)특이점을 피하고 (c)목표 도달하나"를 생성.**
= 닫힌사슬 **결합(coupled) 제약** 하의 경로/IK 생성. 리더 선택이 팔로워 feasibility를 결정하고, **파지 pose가 그 결합 관계를 바꿈.**
- 단순 IK: 도착 관절만 줌, "가는 경로의 팔로워 feasibility"는 안 봄.
- 순진한 플래너: 리더 경로 짜고 팔로워 IK 확인·재시도 → 파지마다 feasible 영역 다르고 재계획 비쌈.
- **RL**: "파지 보고 팔로워-feasible 리더 경로"를 데이터로 내재화 → 재계산 없이 생성. **여기서 RL이 IK/플래너 대비 우위(제약 하 경로결정).**

---

## 2. GNN 정당화 (특성별, 정직하게)
"kinematic graph 하 IK 학습" 관점에서 GNN 특성:
| 특성 | 유효성 |
|---|---|
| **message passing이 IK 사슬계산과 동형** (base→joint→EE→rod 전파 = Jacobian 역전파 구조) | ✅ 강함 — IK 흉내에 자연스러운 계산그래프 |
| **닫힌사슬 루프 + 결합 제약 표현** (grasp 엣지2 + rod = 리더↔팔로워 feasibility 결합) | ✅ 강함 — 리더 상태가 rod 건너 팔로워로 전파 |
| **내력 = 루프 성질** (양팔 상쇄 wrench = grasp 엣지 루프) | ✅ 강함 — §4 |
| 관계표현(grasp 엣지 값) | △ MLP도 flat 입력으로 흉내 가능 |
| 순열불변·가변구조 | ✗ 파지·base엔 무관, **로봇 종류에만** |
- **결론**: 파지 일반화 "만"으론 GNN 이론근거 약함(MLP ablation 필수). 근데 **결합 제약·내력·IK 사슬 관점**에선 GNN이 구조적으로 유리 → 이게 정당화 논거.
- **MLP vs GNN ablation은 필수** (파지·내력 각각).

## 3. Hong2025 대비 차별 (냉정)
| | Hong2025 | 우리 |
|---|---|---|
| 구조/액션/팔로워 | 리더-팔로워 / 관절증분 / IK | **같음** |
| 리워드(r_dist,r_ik,r_sing,r_coll) | 있음 | 유사(feasibility 넣으면) |
| 관측 | flat 관절각+목표 | **GNN 그래프** ← 차별1 |
| 일반화 | **없음(고정)** | **파지·base(·로봇)** ← 차별2 |
| 내력 | force agent(admittance, flat) | **GNN 기반 내력 조절** ← 차별3(§4) |
→ **메소드 골격은 Hong2025과 유사. 차별 = (1)GNN관측 (2)형태 일반화 (3)GNN 내력.** 파지·base 일반화 "단독"은 증분적 → 아래 기여로 승부.

## 4. ★ 추가목표: GNN 기반 내력(internal force) 조절 (2026-07-27 채택)
**동기**: Hong2025(force agent flat)·DA-VIL(단일팔 중심 가변임피던스, GNN아님) 사이 빈자리 = **닫힌사슬 양팔 내력을 GNN으로 표현·조절.**
**GNN 특성**: 내력 = 두 grasp 엣지 + rod가 이루는 **루프**의 상쇄 wrench → message passing이 "두 팔이 rod로 어떻게 상호작용, 어느 관절이 내력에 기여"를 구조로 표현. 파지보다 GNN 정당화 강함.

**단계 (rigid→compliant):**
- **4a (값쌈, rigid)**: 현 rigid 용접 + antagonistic 내력 페널티 → "GNN이 저내력 협응 학습하나" + GNN vs MLP(내력 표현 우위). 한계: rigid는 내력이 solver에 흡수돼 조절 실익 약함(sim-to-real·안정성 논거만).
- **4b (승부, compliant)**: rod-hand를 D6 compliant(스프링) → 내력이 **실제 비용**(미끄러짐·파손) → "GNN 기반 가변 내력 조절"이 진짜 기여. 큰 재작업(동역학·재학습, 예전 plan에 D6 설계 있음). 4a 유망하면 착수.

## 5. 실험 로드맵 (게이트)
1. **파지 변이 학습**(진행 중) → held-out 파지 zero-shot success. (디딤돌: GNN이 형태변이 다루나.)
2. **GNN vs MLP ablation (파지)** — 파지에 GNN 필요한가. MLP≈GNN이면 "GNN은 결합/내력/로봇에서만".
3. **feasibility 리워드**(r_ik+r_sing, Hong2025식) → §1 결합제약을 명시 학습 + 플래너 대비 우위(제약 하 경로).
4. **base 간격 일반화** (base-rel 엣지).
5. **★ 내력 4a(rigid 페널티) → 4b(compliant 가변조절)** — GNN 내력 기여.
6. (최종·먼목표) 로봇 종류/DoF 일반화 — GNN 타입공유만 가능, Hong2025 불가.

---

## 6. 핵심 미해결 / 리스크
- **파지+base 단독 = 증분적**(Hong2025+GNN). 기여는 내력(§4) + 궁극적으로 로봇종류.
- **GNN 우위 = ablation으로 입증 필수**(파지·내력 각각). 안 되면 GNN 차별 흔들림.
- **rigid 내력의 실익 약함** → compliant(4b)가 진짜 승부처지만 큰 작업.
- 모션플래너 대비 우위 = "제약(feasibility·내력) 하 반응적 경로결정" + 일반화. 단순 운반이면 우위 없음 → 제약 필수.
