# Dual-arm Cooperative Manipulation with RL — 연구 소개

> 본 문서는 본 연구의 목표·접근·진행 상황을 공유하기 위한 브리핑입니다.
> 2026-06-09 기준.

---

## 1. 문제 정의

**Task**: 두 대의 Franka Panda 로봇 팔이 협력하여 강체 막대(rod)를 임의의 시작 자세에서 목표 자세로 운반.

**구체적 setup**:
- Robot 1, Robot 2 (양쪽)이 fixed joint로 막대 양 끝과 강결합
- Rod 길이 0.8m, 양 panda_hand가 양 끝 잡음
- 목표: 막대를 6-DOF goal pose (위치 + 자세)로 옮기기
- 평가: 위치 오차 < 20mm AND 회전 오차 < 10°를 만족하면 success

**왜 어려운가**:
- Closed kinematic chain (양 arm + rod) → 양 arm이 협력하지 않으면 내부 응력 발생
- 각 arm은 독립된 7-DOF 매니퓰레이터, 둘이 동시에 같은 rod를 끌고 다녀야 함
- 실제 협동 manipulation의 핵심 — 단일 arm task에는 없는 결합 문제

## 2. 연구 목표

### 핵심 contribution

> **RL 정책이 (rod target pose delta, K_arm1, K_arm2)를 동시에 출력**하는 통합 학습 방법론.

- 기존: 양 arm이 같은 impedance gain (shared K) 사용 (예: DA-VIL)
- 본 연구: 양 arm이 **독립된** K_arm1, K_arm2 — 작업 상황에 따라 정책이 동적으로 조절
- 이론적 직관: 한 arm이 limit 근처에 있을 때 그 arm의 K를 낮추고, 다른 arm이 더 적극적으로 제어 → 협력적 보상

### 비교 대상

- **DA-VIL** (shared K) — 양 arm 동일 stiffness 사용
- **우리 방법** (per-arm K) — 정책이 비대칭 K 출력

### Future work 방향

- 실시간 동적 target 생성
- Obstacle avoidance가 있는 환경
- Sim-to-real

## 5. Stage 0에서 마주친 핵심 문제와 해결

본 연구가 단순한 RL 학습 적용이 아니었던 이유. Stage 0 자체가 일련의 난제였음.

### 문제 1: Reset transient

**현상**: env reset 시 PhysX의 fixed-joint snap이 시스템에 큰 운동에너지를 주입. ~10%의 episode가 시작부터 통제 불능 (rod가 1m 가까이 폭주).

**해결**: env3에 **post-reset settle 30 step**을 빌트인. 정책 action을 첫 30 step 동안 강제로 0으로, target을 reset pose로 동결 → controller가 transient를 damping으로 흡수. episode_length_buf를 freeze해 RL 시간 손해 없음.

**효과**: unstable env 11% → 6%로 감소.

### 문제 2: Settle 데이터의 RL buffer 오염

**현상**: settle 30 step (action=0)이 그대로 SAC replay buffer에 들어가면, 정책이 "action=0이 valid"를 학습하거나 HER이 settle 상태에서 trivial virtual goal을 합성.

**해결**: env3가 `_is_settle_step` flag 노출 → train script가 `valid_mask = ~_is_settle_step`을 추출 → HER buffer의 `add_step`에 valid_mask 추가하여 settle transition을 episode buffer에 안 씀.

### 문제 3: Sampler tail

**현상**: IK solver가 q를 joint limit 경계에 정확히 clamp (margin 0.001 rad 같은 자세 생성). 이런 자세는 작은 외란에도 limit 충돌 → 자가 증폭 폭주.

**해결**: vectorized_pose_sampler에 **joint margin filter** 추가. 모든 joint가 limit에서 ≥ 0.2 rad 떨어진 자세만 수락. cache 재생 35초.

**효과**: 추가로 unstable 6% → 4-5%로 감소.

### 문제 4: 평가 기준의 부정확성

**현상**: 기존 success 카운팅이 `terminated` 신호 (= episode 마지막 step의 위치 오차만 체크)를 사용 → "도달했다가 떠난" 케이스를 fail로 카운트. 측정 자체가 실제 task 의도와 불일치.

**해결**: reward function 의도와 일치하도록 `episode 중 한 번이라도 (min_pos<20mm AND min_rot<10°) 만족`을 success 기준으로 통일. eval_mlp.py / visualize_mlp.py 모두 수정.

**효과**: 평가가 신뢰 가능해짐. 측정치 자체가 task 의도를 반영.

### 문제 5: 회전 학습 부족

**현상**: 학습된 정책의 min_pos는 25mm (threshold 20mm 살짝 초과), **min_rot은 11.4°** (threshold 10° 초과). 위치는 거의 풀렸지만 **회전이 시간 안에 못 풀림**.

**원인**: action_scale_rot = 0.025 rad/step (≈ 1.43°/step). max episode 30 step에서 30° 회전 차이를 메우려면 21 step 필요 → 위치와 동시에 풀 시간 부족.

**해결 시도 중**: `action_scale_rot=0.05` (2배)로 학습 재실행. 회전 자유도 증가.

## 7. 식별된 ceiling 후보 (Stage 0의 한계)

본 task에서 100% success를 막는 요인 분리:

| 요인 | 추정 영향 | 해결 가능성 |
|---|---|---|
| Controller tracking residual ~24mm | 정밀도 ceiling | gain tuning으로 일부 개선 가능 (어렵) |
| 4-5% structural unstable (settle/filter 후 잔여) | 일부 자세에서 controller K/D 미스매치 | adaptive gain 필요 — Stage 1 contribution이 될 수 있음 |
| 학습량 (HER + settle mask로 effective data 절반) | 추가 학습으로 회수 | 30M 시도 중 |
| 회전 학습 약함 | reward/action scale 미설계 | action_scale_rot 증가 시도 중 |

→ **남은 4-5% structural unstable은 Stage 1의 contribution과 직접 연결**. shared K로는 limit 근처 자세에서 폭주, per-arm K로 약한 arm 쪽 K 낮추면 안정화 가능. 이걸 Stage 1에서 입증하면 contribution 명확해짐.

## 10. 동료에게 줄 questions / discussion points

이 연구에서 동료 의견을 구하고 싶은 부분:

1. **Per-arm K vs shared K** — 본 task처럼 양 arm이 fixed joint로 강결합된 경우 per-arm K의 의미가 충분한가? 비결합 협동 (예: 두 그리퍼가 별도 잡기)이 더 흥미로운 sceneraio일 수 있음.
2. **Reward shaping** — sparse-only + HER 조합이 최선인가? 회전 학습 약점이 reward 설계 문제인지 정책 구조 문제인지 더 깊이 살펴볼 가치 있음.
3. **Real-world 일반화** — 현재 sampler가 joint margin filter로 workspace를 약간 축소함. 실제 로봇에서 edge case 자세도 등장할 수 있는데 학습되지 않은 영역으로 들어가는 위험.
4. **DA-VIL과의 공정 비교 기준** — 우리 K_arm1 ≠ K_arm2 가 closed chain에서 본질적 우위인지, 단순히 더 많은 자유도가 있어 학습이 더 잘되는 것인지 분리해 보여야 함.
